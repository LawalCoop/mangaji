# Acompañamiento

Piezas MIDI de dominio público (CC0 1.0 Universal), tomadas de
https://github.com/m-malandro/CC0-midis — ver `LICENSE.txt`.

| archivo | pieza original |
|---|---|
| `zen.mid` | maybe |
| `chill.mid` | sitar-jam |
| `tense.mid` | android-observation-room |
| `war.mid` | frantic-boss-battle |

El navegador no reproduce MIDI: `lib/music.ts` los parsea y los sintetiza, así el timbre lo
pone el mood y la música puede reaccionar a la lectura.
